Index No. (Sequential 1-Based Record Index)

Derived Ordinal Record Position in MPCORB.DAT (k ∈ [1, N], 0-Based Offset k − 1)

1. Formal Definition

In the Minor Planet Center Orbit Database (MPCORB), the Index No. (Index Number; also referred to in astronomical software and database schemas as the Record Index, 1-Based Sequential Catalog Index k, or MPCORB Line Position) is a derived, non-persistent ordinal integer k ∈ ℕ1 (or 0-based offset i = k − 1 ∈ ℕ0) that uniquely identifies a minor planet's sequential row position within a specific release snapshot of MPCORB.DAT after skipping the ASCII header block:

IndexNo(r) = L(r) − Lhdr = i0 + 1 ∈ [1, Nrecords] (Eq. 1)

where:

  • Critical Schema Distinction (Not a Fixed-Width Column): Unlike the Number/Provisional Designation (columns 1–7), H (columns 9–13), or Readable Designation (columns 167–194), Index No. is NOT stored inside the 202-character fixed-width ASCII record. Instead, it is generated sequentially at ingestion/parse time (1, 2, 3, …, N) to index virtualized tables, memory-mapped record arrays, and cross-referenced derived-element collections.
  • Header Offset (Lhdr): Standard MPCORB.DAT files open with a multi-line textual metadata header (typically 41–43 lines describing the epoch, column specification, and download date) terminated by a dashed separator line (----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------). Record Index No. = 1 is the very first 202-character data line immediately following that delimiter (typically 00001, i.e., (1) Ceres).
  • Release-Dependent Volatility: Because MPCORB.DAT is ordered into three contiguous structural blocks—(1) permanently numbered minor planets sorted ascending by catalog number, (2) multi-opposition unnumbered minor planets, and (3) single-opposition unnumbered minor planets—the Index No. of any unnumbered object (and even numbered objects if a record is superseded or re-sorted) shifts whenever new objects are numbered or added between MPCORB releases.
(1), (2), … • Identity holds: IndexNo == N_IAU across all complete MPCORB builds (e.g., Ceres = 1, Pallas = 2, Apophis = 99,942). Invariant in full MPCORB.DAT (Shifts in filtered subsets!) 3. Fixed-Width File Context & Parsing Semantics

  • No Byte Columns Assigned: In the official 202-column IAU MPCORB specification, columns 1–202 are fully allocated to orbital elements, uncertainty parameters, perturbation codes, and designations. Therefore, Index No. occupies 0 bytes in the file and is synthesized monotonically by the parser counter after encountering the 202-hyphen header delimiter line.
  • Distinction from Packed Designation (Cols 1–7) and IAU Number:
    • For numbered minor planets (e.g., 00001 = (1) Ceres, 99942 = (99942) Apophis, A0001 = (100001)), the Index No. in a complete MPCORB.DAT equals the permanent IAU catalog number (1, 99942, 100001).
    • For unnumbered minor planets (e.g., K25Q14A = 2025 QA14), there is no IAU catalog number; the Index No. (e.g., 1,482,917) is solely its ordinal position within that specific MPCORB.DAT file.

4. Worked Examples from MPCORB.DAT

The following two examples illustrate how Index No. behaves for a permanently numbered object versus a newly discovered single-opposition object in MPCORB.DAT (epoch K25BL = 2025 Nov 21.0 TT = JD 2461000.5):

Example 1: (1) Ceres — First Data Record (Index No. = 1)

First 202-character record immediately following the dashed header line in MPCORB.DAT: 

00001    3.35  0.15 K25BL 231.53975   73.28579   80.24963   10.58790  0.0795763  0.21417972   2.7666198  0 MPO925614 11432  98 1801-2025 0.61 M-v 30h JPL 48     1000   (1) Ceres                  20251018
  • Assigned Index No.: 1 (0-based array index 0).
  • Identity Verification: Matches permanent IAU catalog number 1 decoded from columns 1–7 (00001) and columns 167–194 ((1) Ceres).

Example 2: 2025 QA14 — Tail Single-Opposition Record (Index No. > 1.4 × 106)

Single-opposition record located in Block 3 near the end of MPCORB.DAT: 

K25Q14A 27.64  0.15 K25BL 353.30750  347.90466  352.66257    5.38873  0.2564143  0.65913384   1.3073812  0 E2025-R84    27   1    14 days 0.28 M-v 38k MPCLINUX   8403            2025 QA14          20250911
  • Assigned Index No.: Ordinal row count k in Block 3 (e.g., 1,482,917 in a 1.5-million-object catalog snapshot).
  • Interpretation: Because 2025 QA14 is unnumbered (1 opposition, 27 observations), its Index No. has no astronomical meaning outside the loaded file snapshot and must not be confused with an IAU permanent number.
