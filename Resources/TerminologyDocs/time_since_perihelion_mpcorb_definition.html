Time Since Perihelion (Δtq,elapsed) in the Context of the MPCORB Database

Scientific Definition, Keplerian Post-Perihelion Elapsed Interval, Outbound vs. Inbound Phase Progression, and Derivation from MPCORB

1. Fundamental Astrodynamical & Chronological Definition

Definition & Nomenclature: In two-body Keplerian celestial mechanics and ephemeris chronology, time since perihelion (or elapsed time since the most recent perihelion passage, denoted Δtq,elapsed, Δtp+, or τq, and complementary within one orbital period P to time to perihelion Δtq,rem)—is the non-negative scalar duration in Terrestrial Time (TT, expressed in days, Julian years yrJ = 365.25 d, or dimensionless orbital phase fraction Δtq,elapsed / P ∈ [0, 1)) that has elapsed from the minor planet’s previous perihelion passage (Tq,prev, where M ≡ 0° (mod 360°), E = 0°, ν = 0°, minimum heliocentric radial distance rmin = q = a(1 − e)) up to a specified reference epoch tref (by default, the osculating catalog epoch t0).

Under unperturbed two-body Keplerian motion on a bound elliptic orbit (0 ≤ e < 1) with orbital period P = 360° / n (days), the time since perihelion at the osculating epoch t0 is directly proportional to the normalized mean anomaly M0,norm:

Δtq,elapsed(t0) = t0 − Tq,prev = ΔMq,elapsed n = M0 mod 360° n ∈ [0, P)

where M0 is the mean anomaly at osculating epoch t0 (degrees), n is the daily mean motion (deg/day), and ΔMq,elapsed = M0 mod 360° ∈ [0°, 360°) is the non-negative post-perihelion mean anomaly phase:

ΔMq,elapsed = M0 mod 360° = [(M0 % 360°) + 360°] % 360° ∈ [0°, 360°)

Key mathematical and astrodynamical properties of Δtq,elapsed include:

  • Hemispheric Kinematics (Outbound vs. Inbound Leg):
    • If 0° ≤ M0,norm < 180° (body is at perihelion or ascending along the outbound leg toward aphelion), less than half an orbital period has elapsed since perihelion: 0 ≤ Δtq,elapsed < P/2.
    • If 180° ≤ M0,norm < 360° (body has passed aphelion and is descending along the inbound leg toward the next perihelion), half an orbital period or more has elapsed since the previous perihelion: P/2 ≤ Δtq,elapsed < P.
    • At exact perihelion (M0,norm = 0°), the half-open convention [0, P) sets Δtq,elapsed = 0; at exact aphelion (M0,norm = 180°), exactly half an orbital period has elapsed since perihelion: Δtq,elapsed = P/2.
  • Period Complementarity with Time to Perihelion (Δtq,rem): For any bound orbit (0 ≤ e < 1) and any instant t not exactly at perihelion (M(t) ¬≡ 0°), the elapsed time since the previous perihelion and the remaining time until the next perihelion sum identically to one orbital period:
    Δtq,elapsed(t) + Δtq,rem(t) = P = 360° n
  • Half-Period Shift Relative to Time Since Aphelion (ΔtQ,elapsed): Because perihelion (M = 0°) and aphelion (M = 180°) are separated by half an orbital period P/2:
    Δtq,elapsed(t) = (ΔtQ,elapsed(t) + P/2) mod P
  • Generalization to an Arbitrary Observation Epoch (tobs): For any target date tobs ≠ t0 (such as 2026-11-18), propagate M(tobs) = [M0 + n(tobs − t0)] mod 360° and evaluate:
    Δtq,elapsed(tobs) = M(tobs) mod 360° n

2. Contrast Among Apsidal Interval & Epoch Metrics

In astrodynamical catalog applications built on MPCORB.DAT, time since perihelion (Δtq,elapsed) is a scalar elapsed duration (in days or years), whereas previous perihelion date (Tq,prev) is the corresponding absolute epoch (JDTT):

Apsidal Metric Mathematical Definition Domain & Unit Primary Physical & Astrometric Role
Time Since Perihelion (Δtq,elapsed) (M0 mod 360°) / n [0, P) (days / yr / %P) Measures post-perihelion thermal wave lag, volatile sublimation decay, and outbound-leg age
Time to Perihelion (Δtq,rem) [(−M0) mod 360°] / n [0, P) (days / yr / %P) Measures remaining wait until next perihelion (Δtq,elapsed + Δtq,rem = P for M0 ≠ 0°)
Time Since Aphelion (ΔtQ,elapsed) [(M0 − 180°) mod 360°] / n [0, P) (days / yr / %P) Measures post-aphelion elapsed duration ((ΔtQ,el + P/2) mod P = Δtq,el)
Previous Perihelion Date (Tq,prev) t0 − Δtq,elapsed (t0 − P, t0] (JDTT) Absolute calendar/Julian timestamp of the preceding perihelion passage

3. Specific Status and Derivation in the MPCORB Catalog

In the MPCORB (Minor Planet Center Orbit) database published by the International Astronomical Union’s Minor Planet Center (IAU MPC):

  • Implicit Derived Scalar Duration (Not Tabulated): MPCORB.DAT parameterizes orbital phase at epoch via the mean anomaly M0 and does not explicitly store Δtq,elapsed. Instead, Δtq,elapsed is computed directly in closed form from two fixed-width columns present in every MPCORB.DAT record (and optionally anchored to a calendar date via the packed epoch t0 in columns 21–25):
    • Mean anomaly at epoch M0 (columns 27–35, format F9.5, degrees);
    • Daily mean motion n (columns 81–91, format F11.8, deg/day)—or equivalently from semi-major axis a (columns 93–103, format F11.7, AU) via n = 0.9856076686 a−3/2.
  • Domain Guard on Eccentricity (e, Columns 71–79): Verify 0 ≤ e < 1 and n > 0 before evaluating Δtq,elapsed = (M0 mod 360°) / n. For parabolic (e = 1) or hyperbolic (e > 1) trajectories, orbital period P → ∞ and elapsed time since perihelion is instead governed by Barker’s equation or the hyperbolic Kepler equation relative to the single perihelion epoch Tq.
  • Physical & Observational Relevance in Minor-Planet Studies:
    • Thermal Inertia & Post-Perihelion Activity Asymmetry: Subsurface heat conduction delays peak volatile sublimation and dust production in active asteroids and short-period comets past perihelion (0 < Δtq,elapsed < P/2); Δtq,elapsed directly indexes lightcurve and coma-brightness asymmetry models.
    • Normalized Perihelion-Referenced Phase: Expressing Δtq,elapsed / P ∈ [0, 1) provides the standard scale-free orbital phase (0.0 at perihelion, 0.5 at aphelion) used in secular activity profiles and rotational-acceleration (YORP) thermal modeling.
Euclidean Modulo Implementation Note: In C, C#, Java, and JavaScript, the built-in % operator returns a negative remainder if M0 < 0 (for example, (-15.0) % 360.0 yields -15.0 instead of +345.0). Always normalize M0 via dmPeriElapsed = ((m0 % 360.0) + 360.0) % 360.0 and compute dtPeriElapsed = dmPeriElapsed / n so that Δtq,elapsed ∈ [0, P) holds unconditionally for all input angles M0 ∈ ℝ.
