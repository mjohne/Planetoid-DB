4-Hexdigit Flags (Columns 162–165)

16-Bit Orbital Type Enumeration & Special Attribute Bitmasks in MPCORB.DAT

1. Formal Definition

In the Minor Planet Center Orbit Database (MPCORB), the 4-hexdigit flags (formally defined by the IAU Minor Planet Center as the 4-hex-digit orbital type and special classification flags, stored as a fixed-width 4-character hexadecimal string in columns 162–165, 1-indexed, of each 202-character MPCORB.DAT record) constitute a 16-bit unsigned integer bitfield (F ∈ [0x0000, 0xFFFF]) encoding both the dynamical orbit class (low 6 bits) and special observational, perturbation, or planetary-defense attributes (upper 10 bits):

F = ∑k=015 bk · 2k = (N3 N2 N1 N0)16,    OrbitClass = F & 0x003F,    SpecialFlags = F & 0xFFC0 (Eq. 1)

where:

  • N3, N2, N1, N0 ∈ {0, …, 9, A, …, F} are the four hexadecimal nibbles occupying character positions 162, 163, 164, and 165 of MPCORB.DAT (%04X formatting in C/FORTRAN I/O).
  • The low 6 bits (b5 … b0, mask 0x003F) form a mutually exclusive enumeration (0 through 63) specifying the primary dynamical orbit taxonomy (e.g., 0 = general main-belt/unclassified, 1 = Atira, 2 = Aten, 3 = Apollo, 4 = Amor, 5 = Mars-crosser, 6 = Hungaria, 7 = Phocaea, 8 = Hilda, 9 = Jupiter Trojan, 10 = Distant Object / TNO / Centaur).
  • The upper 10 bits (b15 … b6, mask 0xFFC0) act as independent boolean bitmasks combined via bitwise OR (|), flagging whether the orbit is perturbed by major planets, multi-opposition, single-opposition, critical-list numbered/unnumbered, or a Potentially Hazardous Asteroid (PHA).
Figure 1: Bit-level layout of the 4-hexdigit flags in columns 162–165 of MPCORB.DAT. The 16-bit word partitions cleanly into a 6-bit mutually exclusive dynamical class ID (F & 0x003F) in bits b0–b5 and 10 independent boolean attribute flags (F & 0xFFC0) in bits b6–b15.

2. Complete Bit-Level Specification of MPCORB.DAT Columns 162–165

According to the official IAU Minor Planet Center MPCORB.DAT format specification (Orbit Type / Special Flags), every 16-bit flag word F is decoded by separating the low-order 6-bit integer (OrbitType = F & 0x003F) from the individual high-order bitmasks ((F & Mask) ≠ 0):

Bit / Mask Hex Mask Field Type Official MPCORB Meaning & Astrodynamical Criterion
Bits 0–5 0x003F 6-Bit Enum (0–63) Primary Dynamical Orbit Class:
0 = General / Unclassified (Main-Belt & non-resonant); 1 = Atira (Q < 0.983 AU); 2 = Aten (a < 1.0 AU, Q > 0.983 AU); 3 = Apollo (a ≥ 1.0 AU, q ≤ 1.017 AU); 4 = Amor (a > 1.0 AU, 1.017 < q ≤ 1.300 AU); 5 = Mars-crosser (q < 1.666 AU, q > 1.300 AU); 6 = Hungaria (1.78 < a < 2.00 AU, e < 0.18, 16° < i < 34°); 7 = Phocaea (2.25 < a < 2.50 AU, e > 0.10, 18° < i < 32°); 8 = Hilda (3.7 < a < 4.2 AU, e < 0.30, i < 20°, 3:2 JMR); 9 = Jupiter Trojan (5.05 < a < 5.40 AU, e < 0.30, 1:1 L4/L5); 10 = Distant Object (q > 5.5 AU or a > 5.5 AU: Centaurs, KBOs/TNOs, SDOs).
Bit 6 0x0040 Boolean Bitmask Reserved / Legacy Orbit Sub-flag (historically unused or internal MPC flag).
Bit 7 0x0080 Boolean Bitmask Precise / Multi-Apparition Orbit Fit (high-precision astrometric solution).
Bit 8 0x0100 Boolean Bitmask Radar-Observed Object (orbit constrained by planetary radar delay/Doppler astrometry).
Bit 9 0x0200 Boolean Bitmask Unnumbered Object with Multiple Oppositions (or special multi-opposition flag).
Bit 10 0x0400 Boolean Bitmask Near-Earth Object (NEO) Aggregate Flag (q ≤ 1.300 AU; set alongside orbit class 1..4 in newer MPCORB releases).
Bit 11 0x0800 Boolean Bitmask Potentially Hazardous Asteroid (PHA) (MOID⊕ ≤ 0.05 AU and H ≤ 22.0 mag).
Bit 12 0x1000 Boolean Bitmask Perturbed Solution (orbit integrated including gravitational perturbations of all major planets, as opposed to an unperturbed two-body conic fit).
Bit 13 0x2000 Boolean Bitmask Two-Opposition Object (unnumbered minor planet observed across exactly two oppositions).
Bit 14 0x4000 Boolean Bitmask Critical-List Numbered Object (numbered minor planet needing astrometric recovery/follow-up due to growing ephemeris uncertainty).
Bit 15 0x8000 Boolean Bitmask Single-Opposition Object (unnumbered minor planet observed during only one opposition).

3. Parsing Semantics & Implementation Nuances in MPCORB.DAT

  • Why Bitwise Masking (&) Is Mandatory Instead of Equality (==): A common parsing error is testing flags == "0003" to detect Apollo asteroids. Because upper boolean flags (such as 0x1000 for a perturbed solution or 0x0800 for a PHA) are bitwise-ORed into the same 16-bit integer, a perturbed Apollo PHA has hexadecimal string "1803" (or "1C03" if 0x0400 is also set). Consequently, the dynamical class must always be extracted via (flags & 0x003F) == 3, and boolean attributes via (flags & mask) != 0.
  • Mutual Exclusivity of Opposition Flags (0x8000, 0x2000) and Numbered Status: Numbered minor planets (columns 1–7 containing a 5-digit integer or packed number such as 00001 or A0001) have neither 0x8000 (1-opposition) nor 0x2000 (2-opposition) set, though they may carry 0x4000 if placed on the MPC Critical List. Unnumbered objects with 3 or more oppositions likewise have both 0x8000 and 0x2000 cleared.
  • Fixed-Column Layout in MPCORB.DAT: In the standard 202-character fixed-width ASCII format of MPCORB.DAT, columns 162–165 (0-based substring indices 161..165, length 4) immediately follow the 11-character computer/orbital-arc designation (columns 151–161) and immediately precede the human-readable number and name/designation (columns 167–194) and last-observation date YYYYMMDD (columns 195–202).

4. Worked Examples from MPCORB.DAT

The following two records from MPCORB.DAT (epoch K25BL = 2025 Nov 21.0 TT = JD 2461000.5) demonstrate how the 4-hexdigit flag field in columns 162–165 decomposes into its constituent dynamical class and boolean attribute bits:

Example 1: (1) Ceres — Perturbed Main-Belt Dwarf Planet (1000)

Tail fields of MPCORB.DAT record for 00001 (columns 151–202): 

...  JPL 48    1000   (1) Ceres                  20251018
  • Hexadecimal Value: 0x1000 (binary 0001 0000 0000 0000, decimal 4096).
  • Bitwise Decomposition:
    • 0x1000 & 0x003F = 0 → General / Main-Belt orbit (not an NEO, Trojan, Hilda, or TNO).
    • (0x1000 & 0x1000) != 0 → Perturbed orbital solution (integrated with full planetary perturbations).
    • All opposition/PHA flags (0x8000, 0x2000, 0x0800) are 0 (numbered multi-opposition non-PHA object).

Example 2: (99942) Apophis — Perturbed Radar-Observed Aten PHA (1902 / 1D02)

Tail fields of MPCORB.DAT record for 99942 (columns 151–202): 

...  JPL 218   1D02   (99942) Apophis            20210512
  • Hexadecimal Value: 0x1D02 (binary 0001 1101 0000 0010, decimal 7426).
  • Bitwise Decomposition:
    • 0x1D02 & 0x003F = 2 → Aten (a = 0.9224 AU < 1.0 AU, Q = 1.0991 AU > 0.983 AU).
    • (0x1D02 & 0x1000) != 0 → Perturbed orbital solution.
    • (0x1D02 & 0x0800) != 0 → Potentially Hazardous Asteroid (PHA) (MOID⊕ = 0.00026 AU ≤ 0.05 AU and H = 19.09 ≤ 22.0).
    • (0x1D02 & 0x0400) != 0 → Near-Earth Object (NEO) aggregate flag set.
    • (0x1D02 & 0x0100) != 0 → Radar-observed (Goldstone/Arecibo delay-Doppler astrometry included).
