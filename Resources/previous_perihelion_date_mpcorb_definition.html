Previous Perihelion Date (Tq,prev) in the Context of the MPCORB Database

Scientific Definition, Retrograde Non-Positive Phase Propagation, Reference-Epoch vs. Observation-Epoch Formulation, and Derivation from MPCORB

1. Fundamental Astrodynamical & Chronological Definition

Definition & Nomenclature: In two-body Keplerian celestial mechanics and retrospective ephemeris analysis, the previous perihelion date (or most recent perihelion passage date, denoted Tq,prev, Tp,prev, or JDq,prev, and paired half an orbital period away with the previous aphelion date TQ,prev)—is the latest instant in Terrestrial Time (TT, expressed as a Julian Date JDTT or Gregorian TT timestamp) at or before a specified reference epoch tref (by default, the osculating catalog epoch t0) at which a bound minor planet (0 ≤ e < 1) passed through the perihelion (q) of its osculating Keplerian ellipse (M ≡ 0° (mod 360°), E = 0°, ν = 0°, minimum heliocentric radial distance rmin = q = a(1 − e)).

Under unperturbed two-body Keplerian motion with orbital period P = 360° / n (days), the backward-directed previous perihelion date relative to the osculating epoch t0 is bounded within the half-open temporal interval (t0 − P, t0]:

Tq,prev = t0 + ΔMq,prev n = t0 − M0,norm n  ,     −P < Tq,prev − t0 ≤ 0

where M0 is the mean anomaly at osculating epoch t0 (degrees), n is the daily mean motion (deg/day), M0,norm = M0 mod 360° ∈ [0°, 360°) is the elapsed mean anomaly since the preceding perihelion passage, and ΔMq,prev ∈ (−360°, 0°] is the non-positive backward angular phase to perihelion:

ΔMq,prev = −(M0 mod 360°) = − [((M0 % 360°) + 360°) % 360°] ∈ (−360°, 0°]

Key mathematical and astrodynamical properties of Tq,prev include:

  • Strict Non-Positive Backward Propagation (Δt ≤ 0):
    • If 0° ≤ M0 < 180° (body is at perihelion or on the outbound leg receding from perihelion), the most recent perihelion is also the nearest perihelion in time: Tq,prev = Tq,nearest, with elapsed time since perihelion 0 ≤ t0 − Tq,prev < P/2.
    • If 180° ≤ M0 < 360° (body has passed aphelion and is on the inbound leg approaching the next perihelion), Tq,prev reaches back past aphelion by more than half a revolution: Tq,prev = Tq,next − P = Tq,nearest − P, with elapsed time P/2 ≤ t0 − Tq,prev < P.
    • At exact perihelion (M0 = 0°), the half-open convention (−360°, 0°] yields ΔMq,prev = 0° and Tq,prev = t0 (whereas strict past inequality Tq,prev < t0 sets Tq,prev = t0 − P).
  • Generalization to an Arbitrary Observation Epoch (tobs): When correlating recent observations, dust trails, or post-perihelion thermal lag relative to a current observation date tobs ≠ t0 (for example, 2026-11-18), first propagate the mean anomaly to tobs via M(tobs) = [M0 + n(tobs − t0)] mod 360°, and then step backward by the elapsed phase M(tobs):
    Tq,prev(tobs) = tobs − M(tobs) mod 360° n
  • Alternating Ordering with Previous Aphelion Date (TQ,prev): For any reference epoch, the most recent perihelion and aphelion passages strictly alternate at half-period intervals:
    Tq,prev = { TQ,prev + P/2  (if 0° ≤ M0 < 180°)   |   TQ,prev − P/2  (if 180° ≤ M0 < 360°) }
Figure 1: Backward non-positive phase propagation (ΔMq,prev ∈ (−360°, 0°]) for Tq,prev: when 180° ≤ M0 < 360° (inbound arc), the elapsed phase M0 traces back past aphelion Q (TQ,prev) to the preceding perihelion q (Tq,prev) by P/2 ≤ |Δt| < P.

2. Contrast Between Previous, Nearest, and Next Perihelion Branches

In astrodynamical catalog applications built on MPCORB.DAT, distinguishing Tq,prev from Tq,nearest and Tq,next is essential whenever post-perihelion physical processes (such as thermal wave propagation into an asteroid’s subsurface, volatile sublimation lag, or recent meteoroid stream ejection) are indexed by elapsed time t − Tq,prev ≥ 0:

Branch Variant Phase Offset Formula (ΔM) Temporal Bounds Relative to t0 Primary Analytical Use Case
Previous Perihelion Date (Tq,prev) −(M0 mod 360°) ∈ (−360°, 0°] t0 − P < Tq,prev ≤ t0 Retrospective outburst / coma-activity correlation, post-perihelion thermal lag, and historical lightcurve phasing
Nearest Perihelion Date (Tq,nearest) [(−M0 + 180°) mod 360°] − 180° ∈ (−180°, +180°] t0 − P/2 < Tq,nearest ≤ t0 + P/2 Canonical 6-element (a, e, i, Ω, ω, Tp) conversion with minimal two-body perturbation error
Next Perihelion Date (Tq,next) (−M0) mod 360° ∈ [0°, 360°) t0 ≤ Tq,next < t0 + P Forward observation planning, upcoming peak brightness & NEO close-approach alerts

3. Specific Status and Derivation in the MPCORB Catalog

In the MPCORB (Minor Planet Center Orbit) database published by the International Astronomical Union’s Minor Planet Center (IAU MPC):

  • Implicit Derived Chronological Quantity (Not Tabulated): MPCORB.DAT parameterizes orbital phase exclusively via the mean anomaly at epoch M0 and does not store Tq,prev as an explicit column (unlike COMET.DAT, which tabulates a single perihelion date Tq in columns 15–29). Instead, Tq,prev is evaluated directly in closed form from three fixed-width columns present in every MPCORB.DAT record:
    • Packed Epoch t0 (columns 21–25, format A5, 0h TT, e.g., K25BL → 2025-11-21 00:00:00 TT = JDTT 2461000.5);
    • Mean anomaly at epoch M0 (columns 27–35, format F9.5, degrees);
    • Daily mean motion n (columns 81–91, format F11.8, deg/day)—or equivalently from semi-major axis a (columns 93–103, format F11.7, AU) via n = 0.9856076686 a−3/2.
  • Domain Guard on Eccentricity (e, Columns 71–79): Verify 0 ≤ e < 1 and n > 0 before computing Tq,prev (for parabolic or hyperbolic trajectories with e ≥ 1, a single perihelion passage occurs at Tq rather than a periodic sequence).
  • Osculating Backward Propagation Horizon: When 180° ≤ M0 < 360°, Tq,prev steps backward by 0.5P ≤ |Δt| < 1.0P (up to a full orbital period prior to t0). While two-body backward propagation is accurate to within days for main-belt asteroids, objects that experienced a close planetary encounter between Tq,prev and t0 require backward N-body integration or an earlier MPCORB.DAT epoch near Tq,prev for sub-hour precision.
Euclidean Modulo Implementation Note: In C, C#, Java, and JavaScript, the built-in % operator returns a negative remainder if M0 < 0 (e.g., (-10.0) % 360.0 === -10.0). Always normalize M0 into [0°, 360°) via m0Norm = ((m0 % 360.0) + 360.0) % 360.0 and then compute tPeriPrev = t0 - m0Norm / n so that Tq,prev ∈ (t0 − P, t0] holds unconditionally.
